# SpectAcoular
https://acoular.org/spectacoular/install/index.html  
SpectAcoular builds upon the capabilities of Acoular by providing interactive controls 
(widgets) for creating custom graphical user interfaces using the Bokeh visualization library.

Bokeh leverages modern web browsers for rendering and event handling via a high-level JavaScript 
framework. This enables real-time, platform-independent applications, and facilitates the development 
of client-server architectures for distributed processing of microphone array data.
0. installare i driver windows di UMA-16 e sounddevice
1. Creare un venv
2. Installare spectacoular `pip install spectacoular`
3. per testare aprire un terminal nel venv e lanciare `micgeom_app --show` selezionando **minidsp_uma-16.xml**

# AcouPipe
https://adku1173.github.io/acoupipe/   
AcouPipe [KPJS23] is a Python toolbox for generating microphone array data with Acoular [SH17] 
that can be used for training of deep neural networks and other machine learning approaches for 
acoustic source localization and characterization.
